### 🚀 Featured projects

<table>
<tr>
<td width="50%" valign="top">

**🩺 [MedScore / SentryRAG](https://github.com/chrisxcalvin/SentryRAG)**

Multi-signal re-ranking for medical RAG — scores retrieved context on clinical relevance, terminology match, recency, and a demographic noise penalty, so the generator sees fewer contradictory or mismatched chunks. Thesis project, evaluated on PubMedQA and MedQA/USMLE.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![TensorFlow](https://img.shields.io/badge/TensorFlow-FF6F00?style=flat-square&logo=tensorflow&logoColor=white)

</td>
<td width="50%" valign="top">

**🎧 [ResolveIQ](https://github.com/chrisxcalvin/ResolveIQ)**

Human-in-the-loop AI copilot for fintech support triage — classifies ticket urgency, drafts a reply via RAG over help docs and past tickets, and routes it to an agent to approve, edit, or escalate. Corrections feed back into re-ranking.

![Next.js](https://img.shields.io/badge/Next.js-000000?style=flat-square&logo=nextdotjs&logoColor=white)
![FastAPI](https://img.shields.io/badge/FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white)

</td>
