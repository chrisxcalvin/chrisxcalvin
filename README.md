### Featured work

- 🩺 **[MedScore / SentryRAG](https://github.com/chrisxcalvin/SentryRAG)** — Multi-signal re-ranking framework for medical RAG. Scores retrieved context on clinical relevance, terminology match, recency, and a demographic noise penalty, so the generator sees fewer contradictory or age/demographic-mismatched chunks. Thesis project, evaluated on PubMedQA and MedQA/USMLE.
- 🎧 **[ResolveIQ](https://github.com/chrisxcalvin/ResolveIQ)** — Human-in-the-loop AI copilot for fintech support triage. Classifies ticket urgency/category, drafts a reply via RAG over help docs and past tickets, and routes it to an agent to approve, edit, or escalate — with corrections fed back to re-rank future retrieval. FastAPI + Next.js + Postgres/pgvector + LangGraph.
- 💊 **[Medilens-360](https://github.com/chrisxcalvin/Research-Project)** — Full-stack medical prescription analyzer that parses and interprets prescriptions to surface dosage, interaction, and clarity issues for patients.
